EDUZEN Connexion Site

Intégrez votre catalogue de formations EDUZEN dans WordPress — pages indexables par Google, synchronisation automatique, design personnalisable.

WordPress 5.8+ PHP 7.4+ Plan Enterprise GPL-2.0
Télécharger le plugin (.zip) v2.0.0 · eduzen-wordpress-plugin.zip
Introduction

Vue d'ensemble

Le plugin EDUZEN Connexion Site connecte votre site WordPress à votre espace EDUZEN. Il propose trois modes d'intégration selon vos besoins :

📄
Recommandé

Catalogue CPT

Pages WordPress réelles, indexées par Google. Synchronisation automatique quotidienne depuis EDUZEN.

🖼

Iframe catalogue

Shortcode [eduzen_catalogue] — intègre votre catalogue EDUZEN en iframe plein écran sur n'importe quelle page.

⚡

Shortcodes API

Affichage partiel et personnalisé : programmes, sessions, formations via des shortcodes flexibles.

ℹ️
Plan Enterprise requis. Ce plugin est exclusivement disponible pour les clients EDUZEN ayant souscrit au plan Enterprise. La clé API et l'identifiant organisation sont nécessaires pour la synchronisation des données.

Mise en place

Installation

1

Télécharger le plugin

Récupérez le fichier eduzen.zip depuis votre espace client EDUZEN (section Téléchargements) ou directement depuis votre dashboard Enterprise.

2

Uploader dans WordPress

Dans l'admin WordPress : Extensions → Ajouter → Téléverser une extension. Sélectionnez le fichier eduzen.zip et cliquez Installer maintenant.

Ou, en SSH/FTP, décompressez le fichier dans /wp-content/plugins/ :

bash
unzip eduzen.zip -d /var/www/html/wp-content/plugins/
3

Activer le plugin

Extensions → EDUZEN Connexion Site → Activer. L'activation enregistre automatiquement le Custom Post Type et planifie la synchronisation quotidienne.

4

Régénérer les permaliens

Obligatoire après l'activation pour que les URLs du catalogue fonctionnent.

Réglages → Permaliens → cliquez Enregistrer les modifications sans rien changer.

⚠️
Sans cette étape, les pages /formations/ et fiches programme renvoient une erreur 404.

Catalogue CPT

Présentation du catalogue WordPress

Le mode Catalogue CPT crée de vraies pages WordPress pour chacun de vos programmes EDUZEN, indexées par Google avec des balises Schema.org et des URLs propres. C'est l'équivalent du Catalogue de formations WordPress proposé par Digiforma.

Deux types de pages sont générées automatiquement :

PageURLContenu
Archive (catalogue) /formations/ Grille de toutes les formations avec filtre par catégorie, statistiques, prix
Catégorie /formations/categorie/cybersecurite/ Sous-catalogue filtré par catégorie EDUZEN
Fiche programme /formations/ssiap-1/ Description, sessions à venir, modules, prix, statistiques, Schema.org
Catalogue CPT

Synchronisation

Lancement manuel

Dans Réglages → EDUZEN → section Synchronisation, cliquez 🔄 Synchroniser maintenant. Le plugin récupère l'ensemble de vos programmes, formations et sessions depuis l'API EDUZEN, puis crée ou met à jour les posts WordPress correspondants.

Ce que fait la synchronisation

ActionComportement
Nouveau programmeCrée un post eduzen_program avec le titre, la description, l'excerpt et toutes les métadonnées.
Programme modifié dans EDUZENMet à jour le post WordPress existant (titre, contenu, prix, sessions, etc.).
Programme retiré de EDUZENPasse le post en draft — il disparaît du site sans être supprimé.
CatégoriesCrée ou met à jour les termes de la taxonomie eduzen_category.
PermaliensRegénère les règles de réécriture après chaque sync.

Synchronisation automatique

Un événement WP-Cron eduzen_daily_sync est planifié à l'activation du plugin. Il s'exécute une fois par jour et maintient votre catalogue WordPress à jour sans intervention manuelle.

⚠️
WP-Cron et trafic. WP-Cron ne se déclenche que lors d'une visite sur le site. Sur les sites à faible trafic, ajoutez un vrai cron système pour garantir l'exécution quotidienne :
bash — crontab système
0 3 * * * wget -q -O- https://votre-site.fr/wp-cron.php?doing_wp_cron >/dev/null

Catalogue CPT

URLs générées

L'URL de chaque page est composée du slug du catalogue (configurable) et du slug WordPress du titre du programme :

https://votre-site.fr/formations/ssiap-1-agent-de-securite-incendie/
🔗
Conflit de slug. Si une page WordPress classique a déjà le même slug que votre catalogue (ex : une page /formations/ existante), WordPress donne la priorité à la page statique. Supprimez ou renommez cette page, ou changez l'URL du catalogue dans les réglages.

Modifier le slug du catalogue

php — wp-config.php (optionnel)
// Surcharger le slug sans passer par l'admin WordPress
update_option( 'eduzen_catalogue_slug', 'nos-formations' );
// Puis régénérer les permaliens :
flush_rewrite_rules();
Catalogue CPT

SEO & Schema.org

Chaque fiche programme injecte automatiquement un bloc JSON-LD Schema.org de type Course dans le <head> de la page :

json-ld — exemple généré
{
  "@context": "https://schema.org",
  "@type":    "Course",
  "name":     "SSIAP 1 — Agent de Sécurité Incendie",
  "description": "Formation obligatoire permettant…",
  "url":      "https://votre-site.fr/formations/ssiap-1/",
  "provider": { "@type": "Organization", "name": "INSSI Formation" },
  "offers": {
    "@type":         "Offer",
    "price":          1350,
    "priceCurrency": "EUR",
    "availability":  "https://schema.org/InStock"
  },
  "hasCourseInstance": [{
    "@type":      "CourseInstance",
    "courseMode": "onsite",
    "startDate":  "2026-03-23",
    "endDate":    "2026-04-19",
    "location": { "@type": "Place", "name": "Paris 12e" }
  }]
}

Catalogue CPT

Personnalisation visuelle

Le catalogue s'adapte à votre charte graphique via une variable CSS injectée en haut de chaque page de type eduzen_program :

css — injecté automatiquement
:root { --eduzen-primary: #274472; } /* votre couleur configurée */

Tous les boutons, badges, icônes et barres d'accent utilisent cette variable. Changez simplement la Couleur principale dans les réglages — la synchronisation suivante n'est pas nécessaire, c'est pris en compte immédiatement.

Surcharger les templates

Les templates CPT peuvent être surchargés depuis votre thème enfant. Le plugin cherche les fichiers dans cet ordre :

priorité de chargement des templates
1. wp-content/themes/votre-theme/eduzen/single-eduzen_program.php
2. wp-content/themes/votre-theme-enfant/eduzen/single-eduzen_program.php
3. wp-content/plugins/eduzen/public/templates/single-eduzen_program.php (défaut)
💡
Les templates surchargés depuis le thème ne sont pas écrasés lors des mises à jour du plugin. C'est la méthode recommandée pour des personnalisations avancées.
Intégrations

Intégration iframe — [eduzen_catalogue]

Ce shortcode intègre votre catalogue EDUZEN en iframe directement sur n'importe quelle page WordPress. Le design est identique à votre catalogue public EDUZEN — même interface, mêmes couleurs, mise à jour en temps réel sans synchronisation.

[eduzen_catalogue]

Insère votre catalogue EDUZEN en iframe plein écran. La hauteur s'ajuste automatiquement au contenu via postMessage.

slug Identifiant organisation EDUZEN. Défaut : valeur configurée dans les réglages.
height Hauteur initiale en pixels avant le premier message de redimensionnement. Défaut : 800

Exemples d'utilisation

shortcode
# Catalogue avec configuration par défaut
[eduzen_catalogue]

# Hauteur initiale personnalisée
[eduzen_catalogue height="1000"]

# Forcer un identifiant organisation spécifique
[eduzen_catalogue slug="UNIPARISIVRY2025"]

Auto-resize

Le shortcode injecte automatiquement un écouteur postMessage qui adapte la hauteur de l'iframe au contenu. L'iframe EDUZEN émet l'événement { type: 'eduzen-resize', height: number } à chaque changement de hauteur de page.

Thèmes Block (WordPress 5.9+)

Sur les thèmes bloc comme Twenty Twenty-Five, le contenu est enfermé dans un container .is-layout-constrained à largeur limitée. Le shortcode injecte du CSS pour forcer le plein écran :

css — injecté par le shortcode
.eduzen-catalogue-fullbleed {
  width: 100vw !important;
  margin-left:  calc(50% - 50vw) !important;
  margin-right: calc(50% - 50vw) !important;
}
ℹ️
Cette technique (full-bleed CSS) fonctionne quand le container parent est centré — ce qui est le cas de tous les thèmes WordPress standards. Si votre thème utilise un layout inhabituel, créez une règle CSS supplémentaire depuis Apparence → Personnaliser → CSS additionnel.
Intégrations

Shortcodes API

Ces shortcodes interrogent l'API EDUZEN en temps réel et affichent des données partielles. Ils nécessitent une clé API valide. Les réponses sont mises en cache selon la durée configurée (défaut 15 minutes).

⚠️
Pour afficher votre catalogue complet avec les fiches programme, préférez le mode CPT. Les shortcodes API sont utiles pour intégrer des données dans des pages existantes (ex : une session précise sur la page d'accueil).
[eduzen_programs]

Affiche une grille de programmes de formation avec statistiques.

limitNombre de programmes à afficher. Défaut : 10
columnsNombre de colonnes de la grille. Défaut : 3
is_publicFiltrer sur les programmes publics uniquement. Défaut : true
show_statsAfficher les barres de statistiques (réussite, satisfaction). Défaut : true
searchFiltre textuel sur le nom et la description. Défaut : aucun
[eduzen_sessions]

Affiche les sessions de formation à venir.

limitNombre de sessions à afficher. Défaut : 10
columnsColonnes de la grille. Défaut : 2
statusscheduled, ongoing ou completed. Défaut : toutes
formation_idFiltrer par identifiant de formation EDUZEN (UUID).
[eduzen_formations]

Affiche la liste des formations (modules) de votre catalogue.

limitNombre de formations. Défaut : 10
columnsColonnes de la grille. Défaut : 3
searchFiltre textuel. Défaut : aucun

Exemples combinés

shortcodes
# 6 programmes en 2 colonnes, filtrés sur "sécurité"
[eduzen_programs limit="6" columns="2" search="sécurité"]

# 5 prochaines sessions planifiées
[eduzen_sessions limit="5" status="scheduled"]

# Sessions d'une formation précise
[eduzen_sessions formation_id="3f2e1a-xxxx" limit="3"]

Référence

WP-Cron & automatisation

Événement enregistré

HookFréquenceAction
eduzen_daily_sync Toutes les 24h (eduzen_daily) Appelle Eduzen_Sync::sync()

Déclencher manuellement via WP-CLI

bash — WP-CLI
# Déclencher la synchronisation immédiatement
wp eval '$s = new Eduzen_Sync(); print_r($s->sync());' --allow-root

# Voir les crons planifiés
wp cron event list --allow-root

# Vérifier la prochaine exécution
wp cron event list --hook=eduzen_daily_sync --allow-root

Désactiver le cron automatique

Si vous utilisez un cron système à la place, vous pouvez retirer l'événement WP-Cron :

php — functions.php
add_action( 'init', function() {
  wp_clear_scheduled_hook( 'eduzen_daily_sync' );
} );
Support

Dépannage

La page /formations/ affiche une erreur 404

Cause : Les règles de réécriture WordPress ne sont pas à jour.

Solution : Allez dans Réglages → Permaliens et cliquez Enregistrer les modifications. Ce geste régénère les règles htaccess. Si le problème persiste, vérifiez que le module mod_rewrite est activé sur votre serveur Apache.

La synchronisation échoue : "Clé API invalide ou révoquée"

Cause : La clé API a expiré, a été révoquée, ou n'a pas les droits de lecture sur l'endpoint /api/v1/programs.

Solution : Dans votre dashboard EDUZEN, générez une nouvelle clé API (Réglages → Intégrations → Clés API) et mettez-la à jour dans Réglages → EDUZEN. Testez la connexion avec le bouton prévu à cet effet.

Rate limit dépassé — synchronisation bloquée

Cause : L'API EDUZEN limite les appels à 200 requêtes/minute par organisation. Les syncs répétées en développement peuvent épuiser ce quota.

Solution : Attendez 1 minute et relancez. En développement, évitez de déclencher la sync plusieurs fois en moins d'une minute. La sync automatique quotidienne n'atteint jamais cette limite en production.

Les programmes ne s'affichent pas en plein écran (marges importantes)

Cause : Votre thème utilise un container .is-layout-constrained (thèmes bloc WordPress 5.9+) qui limite la largeur du contenu à ~645px.

Solution : Le plugin injecte automatiquement du CSS full-bleed. Si le problème persiste, ajoutez dans Apparence → Personnaliser → CSS additionnel :

css
.eduzen-catalogue-fullbleed,
.eduzen-archive,
.eduzen-single {
  max-width: none !important;
  padding-left: 0 !important;
  padding-right: 0 !important;
}
Une page WordPress classique "prend la place" de l'archive /formations/

Cause : Une page WordPress avec le slug formations (ou votre slug configuré) existe déjà. WordPress donne la priorité aux pages statiques sur les archives CPT.

Solution : Deux options — soit supprimez ou renommez la page WordPress conflictuelle, soit changez le slug du catalogue dans Réglages → EDUZEN → URL du catalogue (ex: nos-formations), puis régénérez les permaliens.

La synchronisation automatique ne s'exécute pas

Cause : WP-Cron nécessite du trafic vers le site pour se déclencher. Sur les sites peu visités, l'événement peut ne pas s'exécuter à l'heure prévue.

Solution : Ajoutez un cron système qui appelle WP-Cron directement :

crontab
0 3 * * * wget -q -O- https://votre-site.fr/wp-cron.php?doing_wp_cron >/dev/null 2>&1

Puis désactivez WP-Cron interne en ajoutant dans wp-config.php : define('DISABLE_WP_CRON', true);

Les fiches programme n'affichent pas de sessions

Cause : Soit vos sessions EDUZEN ont un statut completed ou une date passée, soit elles n'ont pas encore été synchronisées.

Solution : Relancez une synchronisation manuelle. Vérifiez dans votre dashboard EDUZEN que les sessions ont bien le statut scheduled ou ongoing et une date future.

L'iframe [eduzen_catalogue] affiche "www.eduzen.io n'autorise pas la connexion"

Cause : Le shortcode pointe vers www.eduzen.io/embed/ qui est la route autorisée pour l'embedding. Si vous voyez ce message, la route /embed/ n'existe pas ou la slug organisation est incorrecte.

Solution : Vérifiez l'identifiant organisation dans les réglages (ex: UNIPARISIVRY2025). Testez l'URL directement dans un onglet : https://www.eduzen.io/cataloguepublic/VOTRE_SLUG. Si elle charge, l'embed devrait fonctionner.
