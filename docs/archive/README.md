# Archive – rapports et corrections

Les fichiers de ce dossier ont été déplacés depuis la racine du projet pour alléger le répertoire principal.

Contenu typique :
- Rapports de phases (PHASE4_*, PHASE9_*, etc.)
- Corrections TypeScript / build (CORRECTIONS_*, ERREURS_*)

- Guides et plans (README_*, TODO_*, PLAN_*, etc.)

Pour la documentation à jour, privilégier le dossier `docs/` à la racine (hors archive).
